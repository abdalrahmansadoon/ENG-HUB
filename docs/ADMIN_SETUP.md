# إعداد حسابات المديرين في ENG HUB

يمنح ENG HUB صلاحية المدير من مستند Firestore داخل المجموعة `admins`، وليس من حقل داخل مستند `users`. هذا التصميم مقصود حتى لا يستطيع الطالب تغيير دوره بنفسه.

## إنشاء أول مدير أعلى

1. افتح Firebase Console واختر مشروع `eng-hub-5c30a`.
2. افتح **Authentication → Users**.
3. أنشئ المستخدم الذي تريد منحه صلاحية المدير، أو تأكد أن حسابه مسجل بالفعل. يمكن إنشاء الحساب من صفحة التسجيل في الموقع أيضاً.
4. افتح **Firestore Database → Data**.
5. اضغط **Start collection**، واكتب اسم المجموعة `admins`.
6. في **Document ID** اكتب البريد الإلكتروني نفسه الذي يظهر لهذا الحساب في Firebase Authentication، من دون مسافات.
7. أضف الحقول التالية:

| Field | Type | Value |
|---|---|---|
| `email` | string | البريد نفسه كما في Authentication |
| `role` | string | `super-admin` |
| `active` | boolean | `true` |

مثال توضيحي فقط:

```json
{
  "email": "admin@example.com",
  "role": "super-admin",
  "active": true
}
```

يجب أن يكون معرّف المستند أيضاً `admin@example.com` في هذا المثال. استبدل المثال ببريدك الفعلي.

8. سجّل الخروج من ENG HUB ثم ادخل مجدداً بالحساب نفسه. ينبغي أن تظهر لوحة الإدارة.

## إضافة مدير آخر

كرّر الخطوات السابقة للمستخدم الآخر، لكن أنشئ **مستنداً جديداً** داخل المجموعة `admins` بمعرّف بريده الإلكتروني. استخدم القيم التالية:

```json
{
  "email": "another-admin@example.com",
  "role": "admin",
  "active": true
}
```

يمكن تكرار ذلك لأي عدد من المديرين. لا تجمع عناوين البريد في مصفوفة واحدة، ولا تكتب `role: admin` في مستند `users`؛ الموقع لا يعتمد على ذلك الحقل لمنح صلاحية الإدارة.

## الفرق بين الصلاحيات

- `super-admin`: مدير أعلى، ويمكنه الاطلاع على قائمة مستندات `admins`، وله صلاحيات إدارة إعدادات النظام.
- `admin`: مدير للمنصة، ويمكنه إدارة المحتوى وحفظ إعدادات Cloudinary.
- `active: false`: يوقف صلاحية المدير من دون حذف المستند.

## قواعد الأمان

قواعد Firestore في `firestore.rules` تمنع التطبيق من إنشاء أو تعديل أو حذف مستندات `admins`. أضف المدراء أو عدّلهم من Firebase Console فقط. كما تتحقق الواجهة وقواعد Firestore من وجود سجل نشط يطابق بريد المستخدم المصادق عليه.

إذا لم تظهر لوحة الإدارة بعد الإضافة، تأكد من تطابق البريد ومعرّف المستند حرفياً، ومن أن `active` نوعه Boolean وقيمته `true`، ثم سجّل الخروج والدخول مجدداً.
